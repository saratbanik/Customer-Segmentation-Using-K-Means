# Dataset

`Mall_Customers.csv` is the dataset supplied for Internship Task 2. It contains 200 customer records with the fields `CustomerID`, `Gender`, `Age`, `Annual Income (k$)`, and `Spending Score (1-100)`.

The clustering model uses annual income and spending score. The file does not contain item-level purchase histories or transaction records; the spending score is used as a customer-behavior proxy for this exercise.

Original source listed in the task: https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python
